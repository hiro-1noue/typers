# Typers — 企画書

## 概要

**Typers** は、トラックボール向けに最適化された高速軌道入力システムである。
本プロジェクトでは、連続的なジェスチャ入力によって、従来のキーボードに近い入力速度を実現できるかを検証する。

Typers は既存のキーボード操作を模倣するのではなく、トラックボール特有の操作性に適した新しい入力パラダイムの構築を目的とする。

主な特徴：

* 連続運動による入力
* 筋肉記憶を利用した操作
* 軌道ベースの文字生成
* 最小移動量による高速入力

---

# 背景

現在の文字入力システムは、離散的なキー入力を前提として設計されている。

一方、トラックボールには以下のような特徴が存在する。

* 指を離さずに連続操作できる
* 円運動がしやすい
* 手首移動が少ない
* 小範囲で高精度な操作が可能

しかし既存のマウス・ジェスチャ入力システムの多くは、

* 入力速度が遅い
* 視線移動が多い
* 高速入力を前提としていない
* アクセシビリティ用途寄り

という問題を持つ。

Typers では、
「連続軌道入力」が高速な文字入力として成立するかを検証する。

---

# 目的

## 主目的

トラックボールのみを用いて、従来キーボード入力の約80%に相当する入力速度を実現する。

---

## 副目的

* 指移動量の削減
* 視線移動の最小化
* 連続運動による入力体験の実現
* HCI（Human-Computer Interaction）研究として成立するプロトタイプの構築
* 入力性能の定量的評価

---

# 設計思想

## 1. Continuous Motion（連続運動）

入力を「選択操作」ではなく「流れる動作」として扱う。

例：

```text id="n4bw8w"
→ ↓ ↘ ↑
```

のような軌道をそのまま入力として扱う。

---

## 2. Muscle Memory（筋肉記憶）

視覚的にキーを探すのではなく、
軌道そのものを身体で覚えることを重視する。

---

## 3. Minimal Travel（最小移動）

高頻度入力は：

* 短軌道
* 少方向転換
* 小移動量

になるよう設計する。

---

## 4. Trackball-First Design

既存キーボードの模倣ではなく、トラックボール特有の：

* 慣性
* 円運動
* 微細操作

を活かした設計を行う。

---

# 想定入力方式

## 軌道ベース入力

Typers では、
キー入力ではなく「軌道」を文字として扱う。

---

## 例

| 軌道 | 出力 |
| -- | -- |
| →  | あ  |
| →↓ | か  |
| →↑ | さ  |
